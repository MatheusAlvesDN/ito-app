## 2024-06-18 - Identifying Shared Component Patterns for Accessibility
**Learning:** Found that multiple modes (`impostor`, `whoami`, `ito`) share nearly identical `RegisterScreen` components with the same unlabelled icon-only buttons (Back, Add Player, Delete Player, Delete from History).
**Action:** When improving accessibility in one game mode, always check the corresponding screens in other modes to ensure consistent UX improvements across the entire application.
