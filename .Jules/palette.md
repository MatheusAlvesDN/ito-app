## 2024-05-16 - Handling Lucide React SVG button accessibility in Playwright
**Learning:** Adding standard `aria-label` attributes to icon-only buttons (`lucide-react` icons) works perfectly for screen readers, but Playwright scripts often struggle to interact with these elements via `.click()` because they dynamically render SVGs and complex DOM trees that trigger "element is not stable" timeouts. Relying on `page.get_by_role("button", name="...")` may time out due to internal reactivity during re-renders.
**Action:** When adding accessibility to animated/reactive icon buttons in this stack, explicitly use `click(force=True)` or JavaScript injection (`page.evaluate()`) during UI verification to bypass unstable state timeouts, ensuring the test completes while the accessibility structure is verified.
