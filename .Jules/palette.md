## 2025-02-18 - Accessibility Enhancements
**Learning:** Adding `aria-label` to icon-only buttons significantly improves screen reader experience without changing visual design. Using `grep` with context (`-C`, `-A`) is crucial for verifying code structure when file reading is limited or truncated.
**Action:** Always verify the existence and context of UI elements before applying accessibility fixes. Use targeted searches to locate specific components in large files.
