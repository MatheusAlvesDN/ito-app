## 2024-05-18 - Improve icon-only button and toggle accessibility
**Learning:** Found a recurring pattern of missing `aria-label`s on icon-only buttons (like the `ChevronLeft` back button, `Plus` add button, and `Trash2` delete button). Additionally, form labels lacked explicit `htmlFor`/`id` linking to inputs, and toggle buttons missed the `aria-pressed` attribute which is necessary for screen readers. Lastly, keyboard users lacked clear visual focus states since `focus-visible` ring utilities were not applied.
**Action:** Always add descriptive `aria-label`s to icon-only buttons, link inputs to their labels using `id` and `htmlFor`, and use `aria-pressed` for boolean toggle states. Combine these with Tailwind's `focus-visible:ring-2` and `focus-visible:outline-none` for an accessible keyboard experience.
