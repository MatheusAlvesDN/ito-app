## 2026-03-05 - Interactive Element Accessibility Validation\n**Learning:** When using Playwright to verify click interactions on elements with complex DOM structures (like absolute positioning or custom styled React components over a full screen canvas), normal clicks can time out due to strict visibility checks. Furthermore, random inline style updates (like Confetti in `GameScreen`) violate React's strict purity rules in concurrent mode and need to be isolated into a state block to avoid both jank and linting failures.\n**Action:** Apply `force=True` on interaction methods targeting elements covered by overlays, and strictly evaluate nested DOM trees when the application dynamically renders components. Additionally, encapsulate randomized variables using a `useState` lazy initializer to remain pure.
