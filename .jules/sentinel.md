## 2025-04-16 - Infinite Loop DoS from Bounded Randomization Pool
**Vulnerability:** The application was vulnerable to an infinite loop DoS (Denial of Service) when generating unique random numbers between 1-100 for players in GameScreen.tsx. If a user was allowed to add 100 or more players on the preceding RegisterScreen, the `do { num = Math.floor(Math.random() * 100) + 1; } while (usedNumbers.has(num));` logic would enter an infinite loop trying to find an unused number, hanging the thread and crashing the application/browser tab.
**Learning:** This existed because the size of the random selection pool (100) was statically hardcoded, while the number of entities requesting from the pool (players) was unbounded and user-controllable.
**Prevention:** Always cap array sizes or input boundaries to be significantly smaller than any bounded randomization pools they will draw from. Added limits to the frontend player registration flow to cap the maximum number of participants at 20.
