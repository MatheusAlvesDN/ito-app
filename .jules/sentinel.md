## 2024-04-09 - [CRITICAL] Fix Infinite Loop DoS from Unbounded Arrays and Modulo Bias Resampling
**Vulnerability:** Memory Exhaustion and Infinite Loop Denial of Service (DoS). The application allowed users to add an unbounded number of participants (`localPlayers`), which are then processed by a `do...while` resampling loop restricted to generate 100 unique items (`Math.floor(Math.random() * 100) + 1`). If a user provided more than 100 inputs, the program would enter an infinite loop attempting to find a non-existing unused number.
**Learning:** Even simple client-side applications face critical stability and logic denial-of-service concerns if dynamic lists aren't properly bounded, especially when interacting with hardcoded logic constraints or fixed pools (like a pool of 100 numbers).
**Prevention:** Always cap unbounded input arrays and input lengths (`maxLength`) at reasonable limits prior to processing them inside loops, especially bounded or logic-heavy ones.
