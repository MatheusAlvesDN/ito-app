## 2025-03-09 - Client-side state unbounded input and loop exhaustion DoS
**Vulnerability:** The player registration form (`RegisterScreen`) allowed adding an unlimited number of players with unbounded names. This caused a memory exhaustion Denial of Service (DoS) and, when advancing to `GameScreen`, triggered an infinite `do...while` loop (which only generated up to 100 unique random numbers) causing the application to completely freeze and crash.
**Learning:** Client-side state arrays built from user input without length and item count limits can be manipulated to degrade performance or crash the app (memory exhaustion or algorithmic complexity attacks like infinite loops in bounded random generators).
**Prevention:** Always enforce a hard limit on state array size when the array length dictates downstream algorithm bounds. Always use `maxLength` on user-facing text inputs to bound string allocations, and validate both array length and string length before updating React state.
