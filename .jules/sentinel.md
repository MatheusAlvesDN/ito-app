## 2024-03-05 - Infinite Loop DoS from Unbounded Player Input
**Vulnerability:** The application allowed an unlimited number of players to be added in the registration screen. Since `GameScreen.tsx` assigns unique random numbers from 1 to 100 using a `do...while` loop and rejection sampling (`do { num = Math.floor(Math.random() * 100) + 1; } while (usedNumbers.has(num));`), registering more than 100 players causes an infinite loop and application freeze (Denial of Service).
**Learning:** Even simple logic bugs like unbounded arrays can escalate into Denial of Service (DoS) when combined with constraints in downstream data generation (like unique sampling from a fixed pool). Client-side state must have explicit limits that match the assumptions of algorithms using that state.
**Prevention:** Always implement explicit maximum limits on user-generated lists and input lengths (e.g., `maxLength` on text inputs and max items in arrays) before processing them in loops or selection algorithms.
