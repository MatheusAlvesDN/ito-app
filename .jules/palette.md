## 2025-04-04 - [App.tsx Accessibility Improvement]
**Learning:** React fragments and generic `<div>` tags wrapping inputs/buttons without explicit `htmlFor` and `id` associations or `aria-label` properties create disjointed experiences for screen readers. Using icon-only components (like `lucide-react`) without `aria-label` completely hides their function from assistive technologies. Furthermore, relying only on hover states for focus indicators hurts keyboard accessibility.
**Action:** When creating forms, always link labels and inputs via `htmlFor` and `id`. Add clear, descriptive `aria-label`s to all icon-only interactive elements. Consistently implement `focus-visible` Tailwind utilities (e.g., `focus-visible:ring-2 focus-visible:outline-none`) to ensure keyboard navigators have a visually distinct experience without degrading the mouse-user experience.
