## 2024-07-07 - Added ARIA labels to multiple Icon Buttons
**Learning:** Found multiple instances where the generic icon button implementations (like `X`, `Trash2`, `Plus` from `lucide-react`) lacked necessary `aria-label` attributes across different game mode screens (e.g., `src/impostor`, `src/ito`, `src/whoami`). Due to the similar component structure replicated across these modes, fixing accessibility in one mode required porting the fix to the identical sibling components in other modes.
**Action:** When working with localized UI elements, ensure `aria-label` values are consistently applied in the local language (Portuguese) across all replicated component structures. Keep an eye out for icon-only buttons as they are frequently missing required accessibility descriptors.
