## 2026-05-30 - Memoizing Render Computations to Fix Impurities and Performance Bottlenecks
**Learning:** In React, inline calculations using `Math.random` inside the render function of a component trigger `react-hooks/purity` linter errors because `Math.random` is impure and its value will change unpredictably upon each re-render. Additionally, complex inline calculations like creating large arrays of particles can degrade performance when placed directly in the render flow, as they execute on every render.
**Action:** When a static output (like random confetti particles) is only required once per mount, encapsulate the computation using lazy initialization inside `useState` (e.g., `useState(() => ...)`). This avoids recalculating the state during re-renders, thereby satisfying the purity rules and preventing unnecessary performance overhead. Also, wrapping static UI components like `Confetti` in `React.memo` helps avoid re-renders caused by parent state updates.
