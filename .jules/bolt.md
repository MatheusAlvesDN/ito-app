## 2024-06-16 - Prevent Unnecessary Re-Renders in Confetti Component
**Learning:** `Math.random()` calls inside the render function of a component (like inline styles or array mapping) execute on every single re-render. This is a subtle performance anti-pattern in React because it breaks the purity of the render function, making it impossible for React to efficiently bail out of updates. Additionally, if the component is conditionally rendered or re-renders frequently (like the Confetti animation), recalculating 50 particle positions/styles synchronously on the main thread during render can cause jank.
**Action:** When a one-off random calculation is needed (like generating initial positions for particles), encapsulate the calculation using lazy initialization inside `useState(() => ...)` instead of `useMemo` or the render body, as both execute during the render phase and will trigger the impurity warning. This ensures the random values are calculated exactly once when the component mounts.
