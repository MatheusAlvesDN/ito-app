## 2024-05-18 - [Memoizing Randomly Generated DOM Elements]
**Learning:** Using `Math.random()` directly inside functional components (or in inline styles during `map` iterations) not only triggers React `impure function` linting errors, but also causes severe performance thrashing. Upon every component re-render, all random properties are recalculated, forcing React to destroy and recreate the DOM nodes (or rewrite their inline styles) pointlessly.
**Action:** Always wrap randomly generated static properties (like particles, confetti arrays, etc.) inside a `useState` lazy initializer function: `const [items] = useState(() => generateItemsWithRandomValues());`. This guarantees the random logic runs exactly once on mount, satisfying purity rules and preventing wasteful recalculations and visual glitching on subsequent renders.
