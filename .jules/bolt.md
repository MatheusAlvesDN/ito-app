## 2024-05-18 - Wrapping Draggable Items with React.memo
**Learning:** Wrapping individual sortable items (e.g., those using `@dnd-kit/sortable`) in `React.memo()` is a critical performance optimization. It prevents the expensive re-rendering of the entire list when a single item is dragged. Also learned that when defining an anonymous function in `React.memo` (like `const MyComponent = memo(...)`), explicitly setting the `displayName` property (e.g., `MyComponent.displayName = "MyComponent"`) is important to prevent ESLint `react/display-name` warnings and improve debugging in React DevTools.
**Action:** When implementing or optimizing draggable lists in React, always wrap the individual list item components in `React.memo()` and ensure a `displayName` is set if using an anonymous function.
