## 2024-05-24 - React DOM Thrashing via Conditional Main Screen Unmount
**Learning:** Returning a completely different component tree (like an early-return modal overlay) conditionally based on a state (like `viewingPlayer`) causes the entire main application screen to unmount. When the user closes the modal, the main application remounts from scratch. This leads to massive, hidden performance bottlenecks, especially in complex components (like `GameScreen`) where DOM recreation and layout recalculations block the main thread unnecessarily.
**Action:** Never use early returns that completely replace the main component view for transient UI states like modals. Always render modals as overlays absolute-positioned over the persistent main application DOM, effectively retaining its structure and minimizing layout shifts and paint times.
