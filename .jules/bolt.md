## 2025-03-01 - Optimizing Random Selection in Partitioned Datasets
**Learning:** When selecting a random item uniformly from a partitioned dataset (e.g., an object containing multiple arrays mapped by category), using `flatMap` to merge all arrays creates unnecessary memory allocation and O(N) overhead. However, simply picking a random category and then a random item changes the statistical probability distribution (giving disproportionate weight to smaller categories).
**Action:** To optimize without altering statistical probability, sum the lengths of all category arrays (O(K) where K is number of categories), generate a random index up to that sum, and iterate through the categories subtracting lengths until the index is found. This avoids expensive memory allocations while strictly preserving the original uniform probability.
