## 2024-05-05 - Avoid flatMap and Reverse-Lookup for Random Selections
**Learning:** In `GameScreen.tsx`, selecting a random question from multiple themes was done by first merging all arrays with `flatMap`, generating a random index, and then finding the originating theme using `.find()` and `.includes()`. This results in an O(N^2) complexity and creates large, unnecessary intermediate arrays on every render/action.
**Action:** Replace `flatMap` with an O(N) approach. Calculate the total count of items across all partitions, generate a single global random index, and then iterate through the partitions (subtracting the partition length from the global index) until the selected item is found. This avoids array allocations and maintains a uniform probability distribution.
