## 2025-02-28 - Missing React.memo for Draggable Lists
**Learning:** In the `src/ito/GameScreen.tsx` codebase, draggable list items (`SortablePlayerItem`) using `@dnd-kit/sortable` inside a `DndContext` are not memoized. In complex interactive screens, when `orderedPlayers` changes due to dragging, React will unnecessarily re-render all list items if `React.memo` is missing. The memory instruction suggests: "To optimize performance in draggable lists (e.g., when using `@dnd-kit/sortable`), wrap individual list item components in `React.memo` to prevent expensive re-renders of the entire list during drag-and-drop interactions." Also "When wrapping an anonymous component function with React.memo (e.g., const MyComponent = memo(...)), always explicitly append the displayName property (e.g., MyComponent.displayName = 'MyComponent';) immediately after the declaration to prevent ESLint react/display-name warnings and improve React DevTools debugging."
**Action:** When working with `@dnd-kit/sortable` or other list rendering, identify the individual list item components and wrap them in `React.memo` and define `displayName`.
