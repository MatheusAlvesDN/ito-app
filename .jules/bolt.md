## 2025-05-15 - Optimize Random Item Selection in Partitioned Datasets
**Learning:** Using `Array.flatMap()` to merge multiple arrays into a single large array just to pick one random item is highly inefficient in terms of CPU (O(N)) and Memory allocation. Furthermore, finding the parent category of the selected item using `Array.find` and `Array.includes` on the entire dataset causes an additional O(N) lookup.
**Action:** When selecting a random item from a partitioned dataset (e.g., questions grouped by theme), use a weighted random selection across categories (themes) followed by a random pick within the selected category. This architectural pattern avoids expensive flattened object creation (memory overhead) and redundant nested `find`/`includes` lookups (CPU overhead).
