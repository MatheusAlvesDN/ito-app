## 2024-05-14 - Optimizing DND Kit Sortable Lists
**Learning:** In drag-and-drop interfaces built with `@dnd-kit/sortable`, dragging an item triggers frequent state updates in the parent component that tracks the active item and layout shifts. This causes all child list items to re-render constantly, even if they aren't the ones being dragged or changing position, leading to jank on low-end devices.
**Action:** Always wrap individual draggable list item components (like `SortablePlayerItem`) with `React.memo()`. Because they typically only receive primitive props (`id`, `index`, etc.) and don't pass down complex callbacks that change reference every render, `memo` effectively prevents these unnecessary re-renders during the drag interaction. Also, always remember to add `displayName` when using anonymous functions with `memo` to keep DevTools readable.
