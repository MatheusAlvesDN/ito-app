## 2024-05-24 - Optimize Confetti generation to prevent layout thrashing and stabilize visual effects
**Learning:** In React, generating an array of random objects containing random values (`Math.random()`) directly inside the functional component body causes those objects to be recreated on every single re-render. This not only violates the `react-hooks/purity` rule, but for highly animated visual elements like Confetti, it causes the particles to violently reposition and change speed (causing flickering and DOM reflows) during unrelated state updates.
**Action:** Use a `useState` lazy initializer function (e.g., `const [particles] = useState(() => Array.from(...))`) for logic that depends on `Math.random()` and only needs to be computed once per mount. This keeps the values stable, bypasses the linter error without suppressing it, and drastically cuts down on component execution time.
