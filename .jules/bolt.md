## 2024-05-19 - Avoid O(N^2) reverse-lookup logic in random item selection
**Learning:** Selecting a random item from partitioned datasets using a flatMap followed by finding the reverse mapping with `includes()` results in unnecessary memory allocations (O(N)) and sluggish loop complexity (O(N^2)). In `GameScreen.tsx`, retrieving a random question using `const allQuestions = themes.flatMap(...)` and then `themes.find(t => QUESTIONS_DB[t.id].includes(q))` caused noticeable performance bottlenecks as datasets grow.
**Action:** When extracting a random element spanning multiple categories, compute the total array boundaries and generate a global random index. Iterate across the categories and deduct their length sequentially until the index falls within bounds to extract both the subset array and item in O(N) linear time without extraneous allocations.
